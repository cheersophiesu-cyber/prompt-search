# 同款匹配与证据判断

## 先找效果，再找词

「同一主题」不等于「同款效果」。例如都画猫，还需比较是纸片拼贴还是毛毡玩偶，是否采用相同构图、主体变形、光线、背景和版式。列出三至五项最能区分目标的视觉特征，用于搜索和筛选。不要把一张被多处搬运的图算作多次复现。

搜索可从「效果短名 + 提示词」「视觉特征 + 教程」「作者名 + prompt」开始，结合平台话题、关联推荐和用户给出的关键词。对具体平台使用实际可用的原生搜索或 `site:` 搜索。优先检查少量真正匹配的帖子，数量不是质量分数。

有多个版本时保留时间线：原帖发布时间、作者补词时间、修改版时间、反馈时间。后来的“成功了”不自动证明早先版本，也不自动证明用户拿到的这一版。

## 评论区核验顺序

1. 正文末尾、轮播教程页、图片中的文字和置顶评论。
2. 作者自己的评论，以及「求提示词 / 怎么做 / 用什么模型」下的作者回复。展开折叠的完整评论和楼中楼；置顶或高赞本身不能证明是作者。
3. 作者主页中明确关联的续帖或补充教程（仅在有线索时查看）。
4. 「按你的提示词做出来了」「交作业」「同款成功」「不像 / 失败」等反馈及其图片。用回复关系、引用文本或明确说明把反馈连回某一候选版本；模糊相邻关系不够。

记录作者账号或主页和平台作者标识，避免把同名用户、转发者或搬运者当成原作者。提示词在截图中时先读图；OCR 模糊部分标成不确定，不能自行补成完整原词。全文展开失败时记录已见范围。

无法获得评论永久链接时，给帖子链接，加评论者、可见时间、回复对象或截图定位。不要伪造评论 ID、完整访问记录、反馈图片或精确百分比。

## 两条判断轴

先判来源，再判复现，避免把「作者给的」等同于「已经可用」。

| 来源类型 | 可以表述的结论 |
| --- | --- |
| 原帖作者在正文、教程图或本人回复发布完整词 | 找到原帖作者原词 |
| 另一位作者展示同款并公开完整词 | 找到关联同款教程原词；不能说是原帖原词 |
| 评论者提供完整词，作者没有确认 | 社区候选；记录投稿者，待验证 |
| 转发、聚合站、搜索片段、模糊 OCR 或缺失步骤 | 线索或不完整候选，不可升级成可靠原词 |
| 根据画面自行撰写 | 重构/适配稿，明确非检索到的原词 |

| 复现证据 | 结论及限制 |
| --- | --- |
| 独立用户明确使用同版词，附图可见且关键效果匹配 | 有他人图像复现证据；说明观察到的样本及原模型 |
| 独立用户明确说用同版词成功，但无图或图不可见 | 只有文字成功反馈，视觉效果待核实 |
| 作者展示自身结果并给完整流程，没有独立反馈 | 作者展示，尚无独立复现证据 |
| “好看”“收藏”“求词”“谢谢”、只有点赞，或搬运同一结果图 | 不构成复现证据 |
| 多条失败反馈、缺必要参考图/LoRA、原模型不同 | 明示限制；不能推荐为可直接保证复现 |

最终用清楚的等级，而非伪精确分数：

- **证据较强**：完整来源可核验，同款特征匹配，独立反馈能连到这一版词，且已看过匹配的复现图，关键前提无缺失。说明仍未在用户照片或 Seedream 上验证。
- **可测试，尚待验证**：已有完整可追溯词，只有作者展示或文字反馈；或者从别的模型做了适配。指出缺哪种证据。
- **证据不足**：提示词不全、来源或反馈版本无法确认、效果不同或依赖缺失。作为线索交付；不要说已找到可用原词。

来源可靠与跨模型可用是不同问题。即使原词在 Midjourney、Flux 或其他模型中被复现，Seedream 5.0 Pro 仍需另测。某条词在本次照片上效果好，只能补充「本次 Seedream 测试匹配/部分匹配」结论。

## 检索交付示例

用实际证据填充，不能照抄示例当成已完成的检索：

「找到了关联同款教程的完整提示词，属于可测试、尚待验证。作者在置顶回复公开；一位用户明确说按该版本生成成功，但反馈图片未能打开。原教程使用另一模型，下面附 Seedream 适配稿。」

接着给可复制提示词、原文定位链接、两三条关键证据与必要条件，最后邀请上传测试图。若有多个来源，不必输出冗长的搜索日志；把详细证据留在案例文件中。
